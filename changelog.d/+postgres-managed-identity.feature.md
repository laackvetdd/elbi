The store can sign in to an Azure Database for PostgreSQL server that has password sign-in turned off. Set `DB_AUTH=azure-managed-identity` (and `AZURE_CLIENT_ID` for a user-assigned identity) and leave the password out of `DB_URI`: each new connection gets a fresh Entra token from the managed identity, so connections keep working after the first token expires, and no token ever appears in the URI or the diagnostics.
